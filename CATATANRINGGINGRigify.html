  1. (Perbaikan Curve) 
  1. Jika curve hair yang telah dibuat memiliki mirror, silahkan hapus modifiter mirror
  2. Jika origin curve hair mengikuti origin kepala, atau berada sudah berada di tengah X, silahkan set cursor to origin
  3. Lalu masuk kedalam edit mode curve -> duplicate curve (Shift+d)
  4. Selanjutnya masuk ke Editor Type -> 3D Viewport Menu -> Curve -> Mirror -> X Local ,  agar terbentuk curve disebelahnya seperti mirror tetapi sudah terbentuk curve nya sendiri


Jika kamu memiliki curve mesh design rambut duplicate menjadi 3 bagian :

  1. 1 bagian menjadi backup
  2. 1 bagian menjadi curve convert to mesh
  3. 1 bagian menjadi curve only (no bevel) -> pakai addons IKurve

  1. (Curve to Mesh) ketika mempunyai curve rambut yang sudah siap di convert ke mesh, maka
  1. Select Linked from mouse position (shortcut L) -> Separate (shortcut P) -> curve sudah berpisah dari yang utama
  2. lakukan pemisahan 1 curve = 1 object
  3. Masukan semua curve kedalam sebuah collection -> buat backup -> select semua curve lalu
  4. Object -> Convert -> Mesh , convert curve to mesh
  5. Selesaikan (Curve to Bone), selanjutnya
  6. Select all mesh hasil convert, bisa melalui Editor Type -> Outliner -> Collection (tempat curve) -> kelik RMB -> Select Object  lalu
  7. edit mode -> select all -> (shortcut M) -> by Distance (0.001) -> mengurangi vertex agar dapat di bone
  8. Select semua mesh curve hair + Select bone + ctrl+p - with Empty Group (agar mudaah di setup envelop)

  1. lalu buka Editor Type -> Outliner -> “Armature-Hair”, lalu select 1 helai rambut object
  2. Set menjadi Pose Mode , sedangkan mesh 1 helai rambut setup jadi weight paint
  3. Pilih di Editor Type -> Outline -> didalam “Armature-Hair” -> Pilih 1 object helai rambut 
  4. 3d Environtment -> Weight Paint (Ctrl+Tab) -> ubah tampilan jadi Shading Wireframe (agar memastikan area weight sudah ujungnya Merah)
  5. Select bone (Shift+Ctrl+LMB) - pilih Ujung Rambut, dan sekaligus Rapihkan Weight Ujungnya Agar MERAH -> (shortcut Ctrl+L) Select Linked
  6. 3d Environtment -> Weight -> Assign from Bone Envelopes (pasang shortcut biar cepat = Ctrl+K)
    (alasan kenapa 1 helai, karena agar helai rambut lain tidak ikut masuk kedalam helai rambut yang sedang di Assign)
